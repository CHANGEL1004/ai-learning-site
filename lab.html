🔬 스팸 메일 분류 모델 만들기

수업의 핵심 실습입니다. 교과서 92쪽의 네 단계를 실제로 수행합니다. 정답 레이블과 단어 특징을 활용한 교육용 나이브 베이즈 분류기를 브라우저에서 직접 계산합니다. 고급 알고리즘을 외우는 것이 아니라, 훈련과 평가의 의미를 배우는 활동입니다.

② 데이터 준비: 훈련과 테스트를 나누자

가상의 메일 제목을 단어 목록으로 나타낸 데이터입니다. 정답이 있는 훈련 데이터로 학습하고, 학습에 사용하지 않은 테스트 데이터로 평가합니다.

테스트 데이터 6개는 별도 유지
번호메일 제목 (훈련 데이터)정답 레이블학습용 단어 특징
전처리: 메일 제목에서 공백을 기준으로 단어를 추출하고, 같은 단어의 등장 여부를 특징으로 사용합니다. 이 수업 데이터는 사전에 오탈자와 누락 레이블을 확인한 가상의 예시입니다.

테스트 메일의 정답은 모델 예측을 마칠 때까지 숨깁니다.

서로 다른 용도의 훈련 데이터와 테스트 데이터를 확인하세요.

③ 모델 생성: 실제로 모델을 학습시켜 보자

버튼을 누르면 훈련 데이터의 단어 빈도를 세고, 범주별 단어 등장 패턴을 학습합니다. 사용한 알고리즘은 단어 빈도를 활용한 간단한 분류 모델(Multinomial Naive Bayes)의 간단한 교육용 구현입니다.

아직 모델을 학습하지 않았습니다.

🧪 추가 탐구: 모델이 왜 그렇게 예측했을까?

모델 학습 후 직접 단어들을 선택하거나 메일 제목을 입력해 분류 결과를 확인해 보세요. 훈련 데이터가 8개일 때와 16개일 때 결과가 달라지는지도 비교할 수 있어요.

예시:
모델을 학습한 뒤 직접 분류할 수 있습니다.

표시한 점수는 모델 내부 계산에서 정규화한 값입니다. 실제 이메일의 스팸일 확률을 보장하지 않으며, 훈련 자료의 단어에 따라 결과가 달라질 수 있습니다.
