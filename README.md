# 박채은 AI LAB — 다중 페이지 머신러닝 수업 사이트

고등학교 2학년 인공지능 기초, 교과서 88–92쪽에 기반한 15분 모의수업과 추가 탐구용 사이트입니다.

## 페이지
- `index.html` — 메인, 학습 목표, 개별 단원으로 이동하는 학습 카드
- `types.html` — 지도/비지도/강화학습, 분류·회귀·군집·연관 규칙, 유형 선택 실습
- `workflow.html` — 모델 구현의 네 단계, 데이터 전처리, 정확도
- `lab.html` — 훈련 데이터 선택, **실제 다항 나이브 베이즈 분류기 계산**, 테스트 데이터 예측·평가, 혼동행렬, 자유 입력
- `review.html` — 정리·연습 퀴즈 및 Kahoot! 연결

## 사용 및 배포
1. ZIP을 해제한 뒤 `index.html`을 열어 로컬에서 학습합니다. HTML·CSS·JavaScript로 작성되어 외부 서버가 필요 없습니다. (인터넷이 끊기면 웹 글꼴 대신 시스템 글꼴로 표시됩니다.)
2. GitHub에서 **공개** 저장소 `parkchaeeun-ai-lab` 등을 생성합니다.
3. ZIP 내부의 `index.html`, `types.html`, `workflow.html`, `lab.html`, `review.html`, `assets/` 폴더를 **파일 구조 그대로** 업로드합니다.
4. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
5. 배포가 완료되면 `https://<GitHub-ID>.github.io/<저장소명>/`으로 접속합니다.


## 교육적 한계
- 모든 데이터는 가상이며 분류기가 실제 메일을 판정하는 데 쓰일 수 없습니다.
- 단어를 공백 기준으로 구분하는 간단한 다항 나이브 베이즈 분류기입니다. 미등록 단어는 점수에서 제외합니다.
- 모델의 내부 점수는 실제 세계의 정확한 스팸 확률을 뜻하지 않습니다.
- 테스트 데이터 6개만으로 일반적 성능을 확정할 수 없습니다.
- 기존 참고 사이트의 소스코드·문구·이미지는 복제하지 않고 독립적으로 구현했습니다.
