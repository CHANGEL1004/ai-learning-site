Chapter 02. 모델의 학습과 평가

교과서 92쪽의 네 단계와 데이터 전처리·훈련·테스트 데이터의 의미를 이해해 봅시다.

02 · 모델 구현 과정

기계학습은 네 단계로 문제를 해결해요

① 문제 정의무엇을 해결할까?
② 데이터 수집·전처리어떻게 준비할까?
③ 모델 생성어떻게 학습할까?
④ 모델 평가얼마나 잘 예측할까?
스팸 메일 분류는 지도학습의 분류 문제입니다. 정답 레이블을 가진 메일 데이터로 모델을 학습시킨 뒤 별도 데이터로 평가합니다.
Explore the four steps

🔍 각 단계를 눌러 자세히 살펴보기

📚 훈련 데이터

모델에 입력하고 정답을 알려주어 패턴을 학습시키기 위한 데이터입니다.

예: '무료 쿠폰 당첨' → 스팸

📝 테스트 데이터

학습에 사용하지 않은 별도의 데이터로 모델의 예측 결과와 정답을 비교하여 성능을 확인합니다.

예: 새로운 메일의 스팸 여부 예측
학습 데이터에서 높은 점수를 받았다고 해서 처음 보는 데이터까지 잘 예측한다는 뜻은 아닙니다. 별도의 테스트 데이터로 확인해야 해요.

🧼 데이터 전처리 실험: 누락된 값 확인하기

교과서 92쪽에 따르면 데이터를 수집한 다음 결측치·이상치를 확인하고, 필요한 특징을 추출합니다. 아래 예시에서 누락된 레이블을 찾아보세요.

메일광고성 단어일상 단어레이블
무료 쿠폰 안내20스팸
수행평가 일정02정상
당첨자 회의 안내12누락
학습용 데이터에서 빠진 정보가 없는지 살펴보세요.

🧮 모델의 정확도

정확도 = 올바르게 예측한 개수 ÷ 전체 예측 개수 × 100

4개
4개 중 3개라면 정확도는 75%입니다.

이 지표 하나만으로 모든 실제 상황에서의 성능을 보장할 수는 없습니다.
